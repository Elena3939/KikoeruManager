# 多 RJ 合集导入路由

一个外层压缩包可能包含多个以 RJ 命名的目录或内层压缩包。外层文件名没有 RJ 时，普通 RJ 推断仍会返回第一个命中项供任务展示，但这个值不能代表整包业务语义。

## 预检顺序

1. 读取压缩包清单并收集前三层路径中的不同 RJ。
2. 命中至少两个 RJ 时，将任务标记为 `aggregate_archive`，保存 `aggregate_rjcodes` 和数量。
3. 合集跳过整包字幕关联预检和基于首个 RJ 的整体查重。
4. 正常解压后由多作品目录检测拆分子任务，每个 RJ 分别执行字幕、查重、元数据、重命名和分类。

密码库 `filename + rjcode` 权威绑定仍优先于合集识别。清单读取失败或只命中一个 RJ 时继续使用单作品流程，不能猜测合集。

## 验证口径

- 合集中的第一个 RJ 是翻译作品、重复作品或已收录作品时，不能阻断其他 RJ。
- 外层任务日志应显示合集数量，不把整包描述成第一个 RJ 的翻译包。
- 解压完成后每个有效 RJ 都有独立子任务；单 RJ 压缩包行为不变。

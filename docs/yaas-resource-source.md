# YAAS 资源站接入

社团补全和 ASMR 增强下载共用 `resource_source_service.py`。来源入口为
https://alist-public.imoutoheaven.org/ ，内部来源标识为 `imoutoheaven`。
asmr.one 保留原来的文件下载、字幕匹配和入库流程，不增加解压。

## 匹配与选择

- 复用 DLsite 原作、简中及繁中公开翻译关联规则；下载记录同时保留请求 RJ 和实际资源 RJ。
- 仅搜索 `SP后端1[音声分区]` 下的 `DLSite归档合集-离散`、`DLSite月份合集-离散`。
- RJ 精确匹配，防止短号匹配长号；目录、非压缩包不作为下载候选。
- 支持 ZIP、7z、RAR 和 `partN.rar`、`7z.001`、`zip.001`、`rar/r00` 分卷。
  搜索后完整列出命中目录补齐分卷；过滤重复路径、零大小及卷号不连续的组。
- 卷号连续只能证明目录中的已知卷没有编号缺口，不能证明尾卷齐全或包内文件完整。
- 单来源自动选中；多来源必须手选。一个作品只允许选一个资源组，分卷组整体提交。
  来源失败不会自动改用另一个来源。
- 提交前按服务端候选重新校验整个批次，拒绝未知来源、伪造路径和无效选择。

## 下载与任务

YAAS 原包由现有 HTTP/aria2 下载链执行。保存目录为
`http_downloader.download_root`；根目录为空时沿用 HTTP 下载器的 input 默认目录。
密码按 `extract.filename_password_sniff_templates` 中第一个有效模板写入文件名，
默认例如 `RJ123456(south-plus).part01.rar`，保留分卷后缀。

YAAS 任务不附加自动解压、归类、上传步骤，也不直接改变库存拥有状态。
现有目录监听保持原行为。资源站指定密码为 `south-plus`，未解压验证该密码。

`/api/fs/get` 返回的 landing 地址直接交给 aria2 实测会出现 403。
执行时用流式单字节 GET 逐跳取得最终 CDN 地址，再交给 aria2；最多六跳，
每跳限速并校验域名及公网地址。签名直链只留在传输内存，不写任务资源列表或错误记录。
失败重试重新解析链接；有 `.aria2` 控制文件时保留断点，同大小完整文件可复用，
没有控制文件的残片重新下载。完成必须核对实际落盘大小，不能只信 aria2 的完成状态。

两个入口的任务控制沿用 HTTP 暂停、恢复、取消、重试接口，任务中心沿用现有进度字段。

## 缓存与站点限制

社团页面只批量读 PostgreSQL 缓存，后台入队探测；命中后失效社团缓存并通过 SSE 刷新。
完整详情和分页详情使用相同的可下载统计，不改变 `has_asmr_one` 的来源含义。

- 缓存表 `resource_source_probes`：来源、RJ、探测版本组成主键。
- 命中缓存 24 小时，空结果 6 小时，错误 5 分钟；探测错误保留已有候选。
- Redis 共享限速：元数据请求间隔 340ms，下载启动间隔 1 秒。
- 下载最多两个并行任务，每任务单连接、单分片、8MiB/s 上限。
- 分布式租约 90 秒、每 25 秒续期；租约失效停止持有任务。
- HTTP 429/503 触发共享冷却；元数据接口支持数字及 HTTP 日期格式 `Retry-After`。
- 依赖真实 Redis，不在 Redis 不可用时绕过限流。

站点公告的 TPS ≤5、rclone 并发 ≤4、带宽小于 40M 是站点声明，
不是本项目压力测试结论。本实现采用上述更低并发，不探测站点极限。

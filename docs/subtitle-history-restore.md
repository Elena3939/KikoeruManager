# 字幕工作台历史恢复

从社团或操作记录打开作品时，历史入口只提供作品定位信息，不能据此认定 `subtitles` 已生成。任务中心恢复模型保留记录中的实际 `subtitle_dir`，包括 AI 字幕目录，不用作品路径覆盖它。

同一作品已有 pending、processing、paused 或 waiting_retry 任务且尚无 `subtitle_dir` 时，直接显示真实任务的总览和进度。首次抓取和强制重跑采用相同规则；自动聚焦、扫描列表与显式历史恢复都先检查这一状态，不发起缺失字幕目录的文件树请求，也不把运行态覆盖成历史恢复任务。任务发布字幕目录后沿原有状态刷新加载文件树。

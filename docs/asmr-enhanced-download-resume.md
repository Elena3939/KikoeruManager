# ASMR 增强下载断点续传

## 下载缓存

- 每个增强下载会话固定使用一个 `storage.temp_path/asmr_enhanced/<RJ>_<task-id>` 工作目录。
- 未完成文件使用 `<文件名>.downloading` 保存；源站断流后保留该文件。
- 同一任务的网络重试和用户点击重试都复用原工作目录，通过 HTTP `Range` 从已有字节继续下载。
- 重试时原工作目录不存在会直接报错，不会静默创建新目录从零下载。

## 部分失败

- 只要会话仍有失败资源，就保留整个工作目录，不执行重命名、分类或入库。
- 单文件重试会保留未选中的其他失败资源；会话只有在失败资源清零后才执行一次最终入库。
- 任务中心、后台下载卡片和通知均将“有成功文件且仍有失败文件”显示为部分失败。
- 会话统计按原始选择总数和当前剩余失败数累计，不被最后一轮重试的文件数覆盖。

## 旧数据

修复前已经搬入库存的 `.downloading` 文件不自动回迁。它们可能分散在同一作品目录下的多个 `RJ...`、`RJ...(1)` 子目录，自动合并存在覆盖完整文件的风险，应先按文件大小或校验值确认后再人工整理。

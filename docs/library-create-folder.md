# 库存页新建文件夹

库存页的目录工具栏提供“新建文件夹”入口。用户输入名称后，文件夹会实际创建在当前选中库存的当前具体目录下。

## 行为约束

- 仅目录视图显示入口；社团聚合虚拟路径不提供创建操作。
- 创建位置固定为当前面包屑对应的真实目录，不能从请求中跳出该库存的 `browse root`。
- 本地库存使用文件系统创建目录；群晖库存复用 FileStation `CreateFolder`。
- 空名称、`.`、`..`、路径分隔符和空字符会被拒绝；同名文件或目录返回冲突提示。
- 配置为只读的库存不能创建目录。
- 本地创建成功后写入库存索引 mutation 账本，前端先显示创建结果，随后由索引追赶刷新为正式快照。

## 接口

`POST /api/library/browser/create-folder`

请求字段：

- `library_id`：目标库存 ID。
- `parent_path`：库存页当前真实目录。
- `name`：新文件夹名称，只允许单个路径段。

本地库存请求必须携带 `Idempotency-Key`，避免重复提交造成不确定结果。

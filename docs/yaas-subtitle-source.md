# YAAS 字幕来源

字幕爬取沿用库存页入口、繁转简、去广告、过滤规则及字幕配对流程。

## 来源顺序

1. asmr.one 人工中文字幕。
2. YAAS 官中 VTT、风花雪月、北极汉化组的独立作品字幕包。
3. asmr.one AI 中文字幕、YAAS whisper AI 字幕包。
4. 上述字幕候选不可用时，查询 DLsite 关联的简中、繁中版本音声包，所有版本先尝试 MP3 分流，再尝试原档；同类按包体积升序，仅提取字幕。候选不截断为两个，前面的包失败后继续尝试，找到字幕即停止。

同一 asmr.one 目录的人工、AI 字幕分开选择。AI 标记依据来源元数据或路径中的独立 AI / whisper 标记，不因启用 AI 配对就把人工字幕标成 AI。

YAAS 字幕包使用 DLsite / ASMR 作品信息明确给出的原作 RJ。没有原作映射就不拿翻译 RJ 猜测字幕包。文件名中全部 RJ 必须恰好等于目标 RJ，拒绝编号前缀误匹配及多作品包。

## 下载与解压边界

- 字幕下载仅授权上述四个字幕合集内的文件；音声下载仍沿用既有离散音声区白名单。
- 独立字幕包只下载单个 ZIP、RAR、7z，拒绝分卷和整合集，上限 16 MiB。
- 关联中文音声包无固定体积上限，支持单包及连续的 RAR、7z、ZIP 分卷，拒绝未知大小、缺少首卷或中间卷、混合包及错误 RJ。所有卷下载完毕后从首卷读取清单和选择性提取；缺末卷由实际清单读取和解压结果判定失败。
- MP3 分流按文件名中的独立 `MP3` 标记识别（含 `MP3分流`），其它候选归入原档阶段，不根据包体积猜测格式。
- 索引大小与下载前解析出的大小必须一致，流式传输再次检查实际字节数，超量或不完整即失败。
- 解压前检查技术清单，拒绝链接、不安全路径和错误 RJ；只选择 LRC、VTT、SRT、ASS、SSA。
- 单字幕不超过 4 MiB，总字幕不超过 64 MiB、500 个，清单不超过 10000 条。音声文件不会写入临时解压目录。
- 密码使用现有 HTTP 下载文件名密码助手写入 `south-plus`，解压复用现有 7zz 选择性提取、资源槽位及进程取消机制。
- 任务中心记录“字幕爬取临时解压”，关联父字幕抓取任务。临时任务在父任务内执行，避免等待同一 worker 队列产生死锁。临时文件删除后须重跑父任务，不能单独重试临时解压。
- 成功、异常、取消都清理解压工作目录；发布出的字幕随父任务临时目录清理。

## 缓存与展示

字幕合集目录使用进程缓存及 Redis 缓存，保留 6 小时，同一合集并发查询合并为一次索引构建。仅完整读完目录后缓存；目录查询失败不缓存为无字幕。

索引命中表示有待校验候选包，不代表已经解压确认有字幕。实际抓取逐个校验候选，失败原因保留在来源尝试记录中。

AI 字幕显示“AI 字幕”标签，写入 `subtitles [AI]`；人工字幕仍写入 `subtitles`。字幕文件名沿用原配对规则。库存已有字幕计数、扫描、检查及清理同时识别两个目录，本地和群晖行为一致。

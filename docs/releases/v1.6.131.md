# KikoeruManager v1.6.131

本次更新围绕库存入库、压缩包处理、上传下载与社团补全完善日常工作流，增加作品库存定位、后台任务恢复与文件移动恢复能力，并优化大目录处理效率、任务进度反馈和多语言作品展示。

## 新增功能

- **社团作品直达库存**：已收录作品支持从右键菜单前往库存，按当前展示的语言版本定位真实目录；存在多个存放位置时可选择目标库存与目录。
- **后台任务跨页面恢复**：上传、下载工作台支持持久化跟踪任务，切换页面后仍可查看后台小窗、恢复详情与移除任务卡片；浮窗支持拖动及位置记忆。
- **可恢复的文件移动**：库存移动、目录替换、字幕回写及压缩包归档接入统一文件事务，支持暂存校验、原子提交与中断后的继续处理，降低跨挂载搬运中断带来的数据风险。
- **可选宿主快速克隆**：增加宿主文件执行器、安装与验收工具，在满足条件的 Btrfs 文件系统上支持快速克隆。此能力默认关闭，须独立安装并验证路径映射后启用。
- **过滤文件随归档保存**：过滤内容按作品与任务批次存放到压缩包归档目录，保留恢复入口，并关联实际归档记录进行清理。

## 体验与性能优化

- **大规模过滤处理**：复用单次目录扫描与路径树规划，减少大目录重复遍历；过滤恢复记录按条目持久化，重试使用独立批次，保留历史恢复内容。
- **嵌套解压反馈**：统一解压执行并发管理，补充当前嵌套包、层级与单包进度；任务详情、操作历史及通知统一展示解压执行、排队与父子链路耗时。
- **上传进度更准确**：多来源上传按整体字节量累计，统一工作台、后台小窗及实时事件中的速度与剩余时间；等待校验时显示对应阶段，降低高频进度更新造成的数据库压力。
- **浏览器上传更顺畅**：复用文件与文件夹选择入口，优化库存拖入反馈、上传文件树和完成详情；本地库存上传优先在目标目录旁暂存并校验后提交，减少重复搬运。
- **社团浏览与下载预览**：记忆卡片或列表模式、分页大小和发售日期排序，优化作品视口更新；下载来源对比按作品归组展示语言版本，并修正作品选择数量统计。
- **字幕工作台统一**：复用字幕工作台窗口结构，调整导入、检查及后台任务交互，保持布局和状态反馈一致。
- **后台处理响应**：将 DLsite 大页面解析、特典探测数据库操作及 AI 字幕模型加载移出事件循环，减少后台任务对接口响应的影响。

## 问题修复

- 修复嵌套合集目录被折叠后丢失独立作品身份的问题；合集拆分不完整或未派发子任务时停止整包入库，避免错误归类。
- 修复同一 RJ 的本体、特典或其他不同来源被合并为一条问题记录的问题，按实际来源分别保留。
- 修复跳过问题作品时原始压缩包的处理逻辑，原包及分卷进入空闲归档队列，操作记录准确区分归档与删除。
- 修复翻译作品的占位社团信息阻断已验证原作元数据查询的问题，并保留来源可信度校验。
- 修复下载高频回调导致速度采样窗口不断重置、速率及剩余时间异常的问题。
- 修复上传历史终态重复提醒、后台任务卡片状态残留以及上传详情重复完成提示。
- 修复百度网盘上传配置参数错误，并保留实际失败原因以便排查。
- 修复外部搜索快照和任务通知的并发重复写入，避免唯一键冲突与重复通知。
- 修复部分 DLsite 发售日期页面文本匹配异常。
- 修复群晖镜像切换时的分块响应解析与环境变量继承，避免旧配置覆盖新镜像的应用版本和发布信息。

## 更新说明

- 宿主快速克隆保持默认关闭；常规库存、上传及归档流程无需安装宿主服务。
- 该版本包含后端、前端及文件移动模块更新，建议通过完整镜像更新。

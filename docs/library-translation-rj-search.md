# 库存翻译 RJ 关联搜索

同一 DLsite 原作可能存在多个简中或繁中翻译版本，不同翻译者对应不同 RJ。库存搜索不能把这些 RJ 当成同一个作品号，但需要允许用户用同语言的另一个翻译 RJ 定位真实收录目录。

## 匹配语义

- `exact`：搜索 RJ 与库存目录实际 RJ 一致。
- `related_translation`：搜索 RJ 与库存实际 RJ 属于同一 canonical 原作，并且同属简中或同属繁中。
- 简中只关联简中，繁中只关联繁中；不会跨语言关联，也不会把原作、英文或未知语言自动扩展。
- 搜索结果保留库存实际 RJ，并显示“简中关联”或“繁中关联”，避免把关联命中伪装成精确命中。

## 数据与性能

- 关联映射只读 `work_canonical_links`，不在搜索时请求 DLsite。
- `library_owned_works.owned_rjcodes` 只保存库存真实命中的 RJ，不再保存整条关联链。
- 完整 RJ 搜索会把同语言关联号合并为一次库存索引 `IN` 查询，不逐 RJ 建立数据库会话。
- 关联解析使用 5 分钟进程内 TTL/LRU 缓存。
- 已拥有快照中的真实路径可直接生成关联结果，不触发文件系统扫描或群晖 HTTP。
- 只有索引和拥有态快照都没有结果时，完整搜索才进入现有远程兜底；关联号最多扩展 8 个，并发查询且保留部分成功结果。

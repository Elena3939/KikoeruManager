# 社团补全下载与性能验证

## 2026-10-21 来源失效刷新专项验收

本轮基准改前固定为上一轮交付 `ec3bc0f689759ed80968c682766b020fc3bf156e`，只优化后端来源失效后的计算路径。没有部署、没有修改生产数据。

剖析确认整社团深拷贝是主要计算成本：原路径在资源覆盖前后各复制一遍整社团对象。另一个问题是版本失效仅改变键，旧资源覆盖和整社团筛选结果仍占据本机缓存，连续探测累积多代对象。本轮改为复制可修改的作品字典和特典列表，嵌套元数据只读共享，返回响应继续深拷贝；同时释放同社团旧代派生缓存，保留基础状态与其他社团缓存。特典标题比较单独缓存编号、标题和成员下标，动态来源/收录标签仍读当前对象。

保持此前同机、5000 条合成普通作品、百条分页条件，扩大为每侧每轮 200 次来源失效，三轮共每侧 600 次。顺序为改前/改后、改后/改前、改前/改后；各侧开始前统一执行一次 GC，测量期间保持正常 GC。计时包含失效操作、缓存释放及随后第一页重算；另记录覆盖、筛选、排序、归组、统计阶段。改前服务和展示函数均从基准提交读取。

| 轮次 | 改前中位数 | 改后中位数 | 改前 P95 | 改后 P95 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 60.021ms | 30.098ms | 226.225ms | 51.424ms |
| 2 | 60.250ms | 30.581ms | 224.820ms | 51.310ms |
| 3 | 60.080ms | 31.996ms | 228.948ms | 56.708ms |

三轮 P95 均下降，降幅约 75%～77%；中位数下降约 47%～50%。资源覆盖阶段中位数由 32.14～32.30ms 降至 2.05～2.13ms。基础状态均只构建一次；热分页 P95 改前 0.69～0.84ms、改后 0.70～0.76ms，未见明显退步。原始阶段统计及 GC 次数见 [专项原始结果](circle-resource-invalidation-benchmark.json)。GC 次数不等于暂停时长，不能据此把所有尾延迟归因于 GC。

本轮验收通过：三轮来源失效 P95 均低于对应改前结果，且低于 200ms；资源变化后的筛选/统计刷新、嵌套响应隔离、旧代释放不清基础/其他社团缓存、标题计划复用且动态标签更新均有回归验证。相关后端 57 项通过，补充筛选/统计断言后 3 项专项再次通过。本轮没有前端改动。

这仍是隔离数据库、Redis 和外网的计算基准，不代表真实 HTTP 端到端响应。它包含 200 次连续失效，不能把新改前 P95 与下文旧的 20 次样本直接比较；新增的标题缓存收益也没有计入普通作品数据集中的特典负载。

本次只修改本机代码，没有部署，也没有直接修改生产数据。历史任务保持原样；特典错误来源在读取时拒绝，在正常刷新时按精确 RJ 重新探测并纠正。

## 下载契约

- 普通作品点击后先展示弹窗，只发现 DLsite 已验证的原作、翻译及子翻译关系；点击 RJ 排首位并默认勾选，其余按 RJ 稳定排列，支持多个版本同时下载。
- 每个版本按需调用 `/api/circle-completion/download-preview/version`。文件树、来源与文件选择各自保存，取消再勾选不丢失；单项失败可以独立重试。
- 特典没有翻译版，不调用 DLsite 语言发现，只允许精确 RJ。`RJ01699067` 不接受本篇 `RJ01699055` 的候选、文件计划和下载会话。
- 后端提交前核对目标、来源、会话与文件身份，批次先全部验证再入队。额外语言及来源计划共用服务级四路并发与单飞。

## 性能改动

基础作品和资源状态覆盖使用独立版本。来源变化保留基础元数据和特典关系，只更新资源覆盖、筛选、统计及分页缓存。资源结果没有业务变化时不广播，同社团变化按 500ms 合并，包含受影响 RJ 和版本。

前端最多每 500ms 发起一次由探测通知触发的刷新；刷新期间收到的新通知保留到本次请求结束，旧响应不重新写入已失效的页面缓存。官方特典探测仍按提交批次失效，未修改日期 worker、范围租约和不完整扫描判定。

特典归组、标题去重、成员映射和业务标签移到服务端分页前的选择缓存中。前端读取共享展示模型，保留虚拟滚动，只为可见行计算图片状态。作品编号查询与下载预览中的同步数据库操作移入线程。

## 回归与构建

回归覆盖错误特典候选、精确计划与文件身份、多个特典独立预览、已验证语言关联及同语言多版本、发现失败保留点击项、单飞响应隔离、跨 RJ 会话拒绝、同名不同目录、选择保留、单项失败、资源版本不清基础缓存、通知合并和共享展示模型。

后端相关回归 263 项通过；最后补充资源描述回归后，精确身份与分页专项 34 项再次通过。完整回归退出时，异步操作日志线程在测试表已清理后写入 `activity_logs`，记录了缺表告警，pytest 退出码为 0；该告警属于测试关闭顺序，不作为生产日志写入验证。

前端社团组件测试 26 项通过。正式 `npm --prefix frontend run build` 成功，产出预压缩文件 134 个；仍有原有的大分块、Lottie eval 与 VueUse PURE 注释告警。后端使用独立本机 PostgreSQL 55432 测试集群，不接生产数据库。

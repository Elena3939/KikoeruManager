# DLsite 翻译作品关联回退

字幕导入依赖原作与翻译版的明确父子关系。批量接口未返回关联链时，可以使用 DLsite 作品页解析结果中的 `parent_workno` 回退，但不能只根据标题猜原作 RJ。

## 判定顺序

1. 优先使用 DLsite API 返回的明确翻译关联。
2. API 没有关联时，只接受作品页解析得到的 `parent_workno`，且来源必须是 `translation_page` 或 `page_metadata`。
3. 标题中的简体、繁体或英文标记只补语言，不生成父 RJ。
4. 标题疑似翻译但页面没有父 RJ 时，保留“关联链不完整”状态，不缓存为已确认关系。

`RJ01606254 -> RJ01606253`、`RJ01583281 -> RJ01583280` 属于页面父作品回退可确认的关系。

## 重试终止

`dlsite_linkage_uncertain` 使用既有延时重试次数。达到上限后任务进入 `WAITING_MANUAL`，写入问题作品并移出自动重试队列，不再无限重试，也不把疑似翻译作品错误归到猜测的原作。

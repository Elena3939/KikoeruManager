# 社团补全外部搜索跳转

社团补全作品页会在当前分页首屏渲染后，异步探测 AnimeShare 和南+。卡片 / 列表底部固定显示两个站点的真实 favicon，并通过右上角状态徽标区分查询中、命中、未命中、不可用和失败；这些状态不参与缺失数量、库存收录、可下载状态、下载任务或任务中心。

AnimeShare 与南+按当前作品的 canonical 关联链整理原作、简中、繁中三个现有展示语言组，每组只查询一个代表 RJ，避免同语言多版本把远程请求数放大。外站结果需要提取 RJ 号，和当前查询 RJ 使用相同前缀、相同位数且数字差不超过 1 的规则匹配；不使用标题相似度判定。

南+搜索通常需要登录态。在“设置工作台 → 外部服务 → 社团补全外部搜索”填写南+ Cookie 和可选代理。Cookie 只在后端请求时使用，配置接口和日志显示为 `********`；点击输入框右侧眼睛时，设置页会按需读取并仅在当前页面显示原值，保存未修改的脱敏值会保留磁盘中的真实 Cookie。服务端请求会使用与 Edge 登录会话兼容的浏览器请求头，避免 `cf_clearance` 因自定义程序 UA 被 Cloudflare 误判。未配置 Cookie、命中权限拦截页、未命中或请求失败时仍保留南+图标和对应状态，点击可打开该作品的南+搜索页。

外部搜索结果以 PostgreSQL 的 `circle_external_search_records` 为事实源，按 `source + RJ + 探测协议版本` 全局去重；同一 RJ 出现在多个社团也只保存和查询一次。页面请求只批量读取持久快照，缺失或到期记录写为 `pending` 后由后台 worker 处理，不会因进入页面直接访问外站。命中 30 天后后台复查，未命中 7 天后复查，不可用 10 分钟后复查，错误 5 分钟后复查；南+仍严格单线程且相邻请求至少间隔 10 秒。worker 写入结果后会通过实时事件刷新当前页面卡片。前端仅保留当前会话的短期渲染缓存；南+浏览器请求协议变更会递增记录版本，旧结论自动失效。

南+搜索受站点限流约束，后端为南+单独维护串行锁，相邻请求至少间隔 10 秒；AnimeShare 仍可按总并发上限并行。设置页“测试南+连接”复用同一串行链路，只检查搜索页权限和连通性，不写作品搜索缓存。

单个帖子或单个语言版本直接新窗口打开；多个帖子或语言版本显示社团页风格的选择弹窗。

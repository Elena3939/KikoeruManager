# 社团补全外部搜索跳转

社团补全作品页会在当前分页首屏渲染后，异步探测 AnimeShare 和南+。卡片 / 列表底部固定显示两个站点的真实 favicon，并通过右上角状态徽标区分查询中、命中、未命中、不可用和失败；这些状态不参与缺失数量、库存收录、可下载状态、下载任务或任务中心。

AnimeShare 与南+按当前作品的 canonical 关联链整理原作、简中、繁中三个现有展示语言组，每组只查询一个代表 RJ，避免同语言多版本把远程请求数放大。外站结果需要提取 RJ 号，和当前查询 RJ 使用相同前缀、相同位数且数字差不超过 1 的规则匹配；不使用标题相似度判定。

南+搜索通常需要登录态。在“设置工作台 → 外部服务 → 社团补全外部搜索”填写南+ Cookie 和可选代理。Cookie 只在后端请求时使用，配置接口和日志显示为 `********`；保存未修改的脱敏值会保留磁盘中的真实 Cookie。未配置 Cookie、命中权限拦截页、未命中或请求失败时仍保留南+图标和对应状态，点击可打开该作品的南+搜索页。

后端使用进程内 TTL/LRU + Redis JSON 缓存、同 RJ 单飞和总并发上限。外部探测失败不阻塞 `/works` 主请求；前端每 6 件作品分批渐进加载状态，切页时取消旧请求，完成后缓存整页结果。批次请求异常时，尚未完成的作品会落为失败状态并保留兜底搜索地址，不会永久停留在查询中。

单个帖子或单个语言版本直接新窗口打开；多个帖子或语言版本显示社团页风格的选择弹窗。

# Prekikoeru 产品介绍

## 1. 项目概述

Prekikoeru 是一个围绕 DLsite 音声作品整理场景构建的本地整理工具。它的核心不是“单次解压”，而是把一套长期可维护的整理流程固定下来：

- 输入
- 识别
- 查重
- 解压或已有目录处理
- 元数据抓取
- 重命名
- 过滤
- 分类
- 归档

同时，项目还扩展了字幕驱动的 ASMR 同步下载、库存打包、密码库清理和远端查重等功能。

## 2. 适合谁使用

适合以下场景：

- 经常整理 DLsite 音声作品压缩包
- 需要稳定的库存命名与分类规范
- 需要把旧库存重新清洗一遍
- 需要同时维护本地库和远端 Kikoeru 库
- 需要把字幕目录与下载流程串起来

## 3. 核心模块说明

### 概览

查看运行状态、监视器状态和总体统计。

### 任务队列

查看所有任务，观察当前步骤、进度和异常信息。

### 问题作品

集中处理查重冲突、重复作品和关联作品问题。

### 库存管理

浏览库存目录和作品信息。

### 密码库

管理解压密码，并配合定时清理功能控制无效密码积累。

### 已有文件夹

对非软件解压生成的旧目录做重新识别、查重、重命名和分类。

### 同步下载

以字幕文件夹为入口，识别 RJ 号并发起 ASMR 同步下载任务。

### 库存打包

对库存目录执行压缩、复制目录结构、断点恢复等操作。

### 设置

集中管理所有可配置项。

### 日志

查看系统运行日志，便于定位解压失败、请求失败和配置异常。

## 4. 典型使用流程

### 普通压缩包整理

1. 配置输入目录和库存目录
2. 把压缩包放入输入目录或前端上传
3. 系统扫描并创建任务
4. 自动完成处理步骤
5. 在问题作品页检查冲突项

### 清洗历史库存

1. 配置已有文件夹目录
2. 扫描历史目录
3. 先看增强查重结果
4. 再决定是否批量处理

### 字幕驱动下载

1. 配置字幕目录
2. 扫描字幕文件夹
3. 预览对应可下载作品
4. 启动同步下载

## 5. 配置思想

Prekikoeru 的核心思想是“把规则放到配置里”。

你可以长期维护：

- 解压密码列表
- 过滤规则
- 重命名模板
- 分类规则
- 远端查重策略
- 自动流程开关

这样同类文件以后进入系统时，会按同一套标准处理。

## 6. 项目当前具备的专项能力

- Kikoeru 服务器查重
- 关联作品增强查重
- 已有文件夹缓存与批量处理
- 配置重载接口
- 密码库智能清理
- 已处理压缩包清理
- ASMR 下载失败任务重试
- 库存打包历史与断点状态

## 7. 使用建议

- 第一次使用不要直接对正式库存全量处理
- 先准备测试目录验证规则
- 重命名模板和分类规则确定后，再打开自动监视
- 对已有库存做批量处理前一定要备份

# KikoeruManager 软件介绍

KikoeruManager 是一个面向 DLsite 同人音声库存的桌面化管理工作台。它把“下载资源、识别压缩包、自动解压、补元数据、分类入库、字幕配对、冲突处理、历史审计、通知提醒”做成一条可追踪、可重试、可人工介入的业务链路。

它适合已经有长期库存维护需求的用户：本地多盘、群晖远程库、字幕目录、ASMR 缺失补全、外链下载、百度网盘资源、解压密码库、邮件提醒和批量任务都能在同一个界面里处理。

## 核心业务链路

### 1. 压缩包识别、解压与入库

- 自动识别 ZIP、RAR、7z、tar、gz 和常见分卷压缩包。
- 支持错误后缀修复、非压缩后缀伪装包识别、带垃圾前缀的嵌入 ZIP payload。
- 支持密码字典自动尝试、嵌套压缩包递归解压、单层包装目录折叠。
- 过滤规则命中的文件和目录会进入任务恢复区；任务完成后可在任务中心右键还原，且不会覆盖同名库存内容。
- Linux / Docker 下遇到超长顶层目录时，会把顶层目录流式重映射为安全短名后继续解压，避免 255 字节文件名限制直接中断。
- 解压失败、重复作品、需要人工判断的作品会进入问题作品工作台。
- 成功入库后可按社团、系列、RJ 段等规则整理目录。

### 2. DLsite 元数据与重复处理

- 自动抓取 RJ 标题、社团、CV、标签、封面、系列等元数据。
- 支持 DLsite 关联作品链路，识别原版、翻译版、多语言版本关系。
- 冲突处理支持保留新版、跳过、合并，结果会写入任务和操作历史。
- 问题作品不只是失败列表，而是人工决策工作台。

### 3. 库存主工作台

- 同一页面管理本地库存和 Synology FileStation 远程库存。
- 支持目录浏览、搜索、重命名、删除、批量删除、移动、拖拽移动。
- 文件列表支持 Windows 式多选、框选、右键菜单、拖动幽灵和面包屑投放。
- 本地移动会先做后端预检：同名文件夹进入自动合并，真正的文件撞名或类型冲突再交给用户选择保留两者、覆盖或跳过。
- PostgreSQL 库存索引用于本地库存的 RJ 搜索、库存大小统计和问题作品路径拾回，基于复合索引和 `pg_trgm` 支撑几十万文件目录浏览；Synology FileStation 远程库存不再创建库存索引，浏览 / 搜索走群晖原生接口。
- 本地库存外层文件夹大小可复用索引展示；删除、批量删除和移动完成后会刷新受影响外层目录的聚合大小，删除确认和文件树读取仍按当前文件系统实时统计。
- 社团聚合视图只做后端包装展示：有真实路径的作品行、目录行和子目录行直接用真实路径执行；只有社团壳、汇总行这类没有唯一真实路径的包装行，才在点击时由后端展开成真实目标。
- 写操作会同步更新索引，避免每次操作后重新全量扫描。

### 4. 下载、上传和外链资源

- ASMR 同步下载：扫描字幕目录，找缺失 RJ，批量下载、重命名、分类入库。
- RJ 下载的指定目录弹框：本地库存优先使用索引导航和全库索引搜索，远程库存按当前目录高效浏览；增强下载的整体进度与速度按实际传输字节统计，不按文件数量或文件平均速度估算。
- HTTP 外链下载：支持普通 HTTP、PikPak、Google Drive、Gofile、OneDrive、Transfer.it 等平台解析，预览树可按平台、目录和单文件选择；PikPak 支持链接内 `?pwd=`、链接后提取码和下一行提取码，调用平台接口前会把密码与纯分享路径分开传递；PikPak 一键清空最多并行处理 3 个独立账号，清理完成后读取本次清理写入的缓存状态，不再追加一次全账号强制检测；PikPak“检测全部”最多并行检测 5 个账号，只读取页面实际使用的账号可用性和容量，不请求无人使用的转存额度与 VIP 信息；Gofile 支持在设置页单独配置文件并发和分片数，默认 2 个文件并发、每文件 5 分片。下载中的文件只保留 `.part` / `.aria2` 未完成标记，只有流正常结束且实际字节数与服务端声明一致后才发布正式文件名。
- 百度网盘工作台：处理百度网盘资源的解析、预览树单文件选择、下载 / 转存和任务状态展示；设置里的“全局同时下载文件数”是所有百度下载任务共享的文件下载额度。预览树重命名按完整文件名编辑，扩展名（包括 `.part1.rar`、`.7z.001` 等分卷后缀）会一并保留；用户填写完整文件名后不会再追加原始后缀。
- 上传工作台：本地目录、单文件、服务端预览上传都走任务中心。
- 复制、上传、下载都采用流式分块，进度和速度会进入任务明细。

### 5. RJ 字幕工作台

- 从库存页发起 RJ 字幕流程；本地库存按本地文件路径处理，只有群晖库存走远程 FileStation。
- 阶段包括扫描 RJ 目录、检查已有字幕、搜索来源、下载原始字幕、清洗、自动匹配、人工筛选、写入 `subtitles/`。
- 字幕过滤只排除带有“无效果音 / SEなし / CUT / MP3”等明确标记的候选；若规则排除了全部候选，任务会直接报告过滤原因，不会再显示成下载失败。
- 支持顺序配对、内容指纹去重、等待人工匹配和手动配对落盘。
- 已有字幕目录会保留在上下文中，不会简单当失败项丢掉。

### 6. 社团补全

- 按社团关键词检索服务器持有作品，列出库存缺失项。
- 支持卡片 / 列表视图、虚拟滚动、封面降级、CV 展示和关联作品链。
- 可批量加入下载任务，和 ASMR 下载链路共用进度、重试和历史。
- 特典探测结果会进入操作历史，命中时展示特典 RJ、标题、发售日和写入统计，未命中时也会保留独立状态。
- 批量找特典会记录原作级 `has_bonus / no_bonus` 状态，并维护轻量隐藏特典命中索引；后续任务先查本地索引，再只扫描未判明的作品和发售日，避免重复深扫 DLsite。
- 支持 IMAP 邮件监听新发售线索。

### 7. 任务中心与操作历史

- 解压、下载、上传、字幕、重命名、备份、同步等耗时操作全部后台任务化。
- 支持暂停、取消、重试、等待人工、等待自动重试和批量处理。
- 任务状态覆盖 `pending`、`processing`、`completed`、`failed`、`paused`、`waiting_manual`、`waiting_retry` 等场景。
- 操作历史按业务树形聚合，不是简单流水账；能看到父任务、子任务、人工处理、失败原因和最终结果。

### 8. 通知模板与邮件

- 内建 SSE 通知中心和前端铃铛。
- 支持 SMTP 邮件发送和 IMAP 邮件监听。
- 邮件模板提供 Block Editor，支持拖拽变量 pill、文件树、RJ 卡片、统计、日志、diff 等业务块。
- 后端统一渲染业务块并清洗 HTML，避免模板逻辑散落在前端。

### 9. 密码、安全与桌面化

- 密码工作台可维护 DLsite 解压密码，并按 RJ + 文件名或通用密码去重合并。
- 解压时自动尝试历史密码，密码库候选会作为兜底完整轮查，减少重复手动输入。
- 安全网关提供访问闸页、阻断页和相关配置。
- Windows 桌面版支持托盘后台运行、开机自启、一键打开 Web 和 `KikoeruManager.exe` 打包。
- Docker 镜像支持前后端一体部署，单镜像内置 PostgreSQL 18，适合 NAS 或服务器长期运行。

## 界面模块

- **仪表盘**：查看库存、任务、问题作品、下载上传和近期活动概览。
- **库存主工作台**：管理本地 / 远程音声库存，执行移动、删除、重命名、字幕任务和备份。
- **任务中心**：集中处理所有后台任务、失败明细、重试和人工等待态。
- **操作历史**：按业务聚合查看处理链路。
- **问题作品**：处理失败、重复、冲突和待人工判断的作品。
- **社团补全**：发现某个社团缺失作品并批量补全。
- **ASMR 同步**：根据字幕目录反查缺失资源并下载入库。
- **百度网盘**：处理百度网盘相关下载 / 转存任务。
- **密码工作台**：维护和复用解压密码。
- **设置**：配置库存、解压、HTTP 下载、AI 字幕、百度网盘、安全网关和通知模板。

## 技术架构

### 后端

- `FastAPI` + `SQLAlchemy` + `PostgreSQL 18`
- `JSONB`、连接池、`pg_trgm` 和库存目录复合索引
- 任务调度和状态持久化
- Synology DSM / FileStation REST API
- aria2 RPC 下载
- DLsite / ASMR 资源解析
- 邮件发送、监听、模板渲染和 HTML 清洗
- 7-Zip / unar / lsar 解压链路

### 前端

- `Vue 3` + `Vite`
- `Tailwind CSS` + `Element Plus`
- `lucide-vue-next` 全站图标
- `@tanstack/vue-table` 库存表格模型
- `@tanstack/vue-virtual` 社团作品虚拟滚动
- `Tiptap` 邮件 Block Editor
- 统一系统弹窗、通知中心、暗黑模式和移动端适配

## 部署方式

- Windows 桌面版：下载 Release 后运行 `KikoeruManager.exe`。
- 源码开发：后端 FastAPI，前端 Vite。
- Docker：使用 `ghcr.io/elena3939/kikoerumanager:<版本号>` 或 `elena39/kikoerumanager:<版本号>`，并持久化挂载 `/app/postgres`；正式 tag 构建会把版本号写入前端静态文件名，避免反向代理缓存旧 chunk 后继续命中同一个 `/assets/*.js` URL。

详细部署命令见项目根目录的 `README.md`、`START_GUIDE.md` 和 `DOCKER_DEPLOY.md`。

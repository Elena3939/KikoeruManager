# 社团作品数量差异修复实测

验证对象：来世猫と未来の大富豪，RG55461。日期：2026-10-19。

## 原因与证据

- 修复前本地 68 条，生产快照 71 条；本地集合是生产集合的子集。
- 缺少 RJ351724、RJ376602、RJ376604，均未合并到其它作品。
- 本次实际请求官方社团列表：第一页 50 条、第二页 20 条，第三页 404；70 条中有 2 条视频，音声 68 条。三个缺失 RJ 在列表响应原文中均不存在。
- 三个 RJ 的官方商品 API 均能返回同社团 RG55461、音声 SOU。另查 RJ351724 商品页面返回 404，正文明确显示当前停售。
- 生产存在三条历史元数据，缓存时间均为 2026-06-18；本地运行修复验证前，这三条元数据数量为 0。
- 实测 ASMR.one 社团目录有 50 条，包含全部三个缺失 RJ。因此不应只靠官方当前在售列表与本机历史缓存发现作品。

## 修改

社团索引增加历史候选发现：读取经过身份、分页、数量和稳定性校验的 ASMR.one 社团目录，对列表及本地缓存之外的 RJ 查询官方商品接口。仅官方返回同 RJ、同 maker_id、work_type=SOU 时加入候选，继续走现有作品链路与入库流程。目录内容本身不直接作为官方作品结论。

本次目录传入后续资源核对阶段复用，避免同一任务重复请求该目录。只验证新增候选，已有作品不重复查询。

## 实测结果

调用实际 index_circle_catalog(force_refresh=True)，运行前本地 68 条且三个目标没有元数据缓存，未从生产复制元数据。

| 指标 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 本地作品总数 | 68 | 71 |
| 相对生产 71 条的缺项 | 3 | 0 |
| 相对生产的额外项 | 0 | 0 |

本次完整索引用时 49.594 秒。此前审计记录为 65.639 秒，缓存条件不同，不能据此计算修复提速比例。本次重点验收作品集合完整性。

30 项相关测试通过，覆盖官方身份不符、视频标题含 ASMR、RJ 被重定向、官方资料缺失、目录不完整、已有候选去重、目录复用、音轨核对及原有性能回归。

原始实测文件位于本机 data/run/circle-count-20261019/，其中 fixed-index.json 保存结果集合与耗时，production.json 为只读生产快照。

## 范围

本次修复补齐该社团全部三个缺项。对于官方公开列表、本地历史资料和资源目录都没有记录的停售作品，现有数据源仍无法发现，不能据此宣称能枚举所有历史停售作品。未部署到生产。
